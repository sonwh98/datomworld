The two guards are now refusals, not `is`, so that a control can observe them firing without a reported failure:
- `injective` throws `{:law-4 :injective :names …}`;

`law-4-controls` replaces the hand-built descriptor map with two real fixtures:

## N3: nested free-env values

New test: `layout-test/free-env-nested-values`. It covers 2 nestings × 4 values × 2 lanes × 2 directions.
- **Nestings:** box `[1 [x]]` (path `[:free-env box 1 0]`) and box `{:nested x}` (path `[:free-env box 1]`).
- **Closure and continuation.**
  - Lowering into a native receiver refuses `:unsupported :free-env-value` with the exact path and 0 attaches.
  - A native source refuses `:non-portable :free-env-value` with key `box` and 0 serves.
  - The reference lane answers `"B"`.
  - The continuation is captured inside `(fn [box] …)` as a tail call. That way its E differs from the free environment only on the lexical `box`, so the carrier itself lifts it.
  - A continuation captured with any non-lexical E is refused earlier by the carrier, as `:inconsistent-state :free-env-mismatch`.
- **Admitted controls.**
  - **Primitive:** the program reads it back through `first`/`get`.
  - **Authentic cursor reference:** minted by `engine/handle-cursor` on the source lane; the program's read goes through that nested cursor.
  - Both cross in both directions through `h/crossed`, with attaches equal to the carried stream identities, and answer the reference value.
