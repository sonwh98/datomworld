# Eval bridge r10: request-boundary slice; bridge incomplete

Added a provisional closed eval request shape and a coordinator entry point that validates it before invoking the existing parser worker. It rejects unknown top-level fields, missing fields, a non-eval goal, malformed source/options shapes, and non-portable data. A rejection retains a portable correlation identity but does not echo unrecognized request fields. This is a boundary check, not proof that otherwise valid options or provenance do not contain caller values; the eventual request producer must construct those fields from compiler metadata only. The field names and validation must be integrated with the eventual stream service and producer as one protocol.
