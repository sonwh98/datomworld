# Eval bridge r8: design gap; bridge incomplete

Generator destruction now releases its dynamic scope dictionary, including cells introduced after function entry, rather than only the original CV vector. The structural regression failed before the change; a pending-oracle suspended-generator fixture produced `DZ` on all four JVM evaluators after it. The installed-export effect was also exercised via actual linker installation and application of the returned closure on all four JVM backends (a stub linker response, not real-service admission): 8 assertions passed.

**Design gap, stop:** generator normal completion currently does not call its cleanup. A pending-oracle probe with a dynamic object binding printed `ZD` on all four evaluators rather than the hand-derived `DZ`. A trial calling cleanup from `php/gen-exit` produced `DZ`, but a destructor throwing during that cleanup re-entered the generator's handler after the state had been closed and yielded `[:thrown "Cannot apply non-function"]` rather than the hand-derived `XA`. The trial was withdrawn. The ordering of closing state, releasing CVs/dictionary, restoring caller handlers/context, and routing destructor exceptions needs a lifecycle design and PHP 8.3 oracle before a safe completion/throw fix. Destruction cleanup with throwing destructors also needs investigation. The generator dictionary work is therefore partial, not a completed lifecycle claim.

The part-7 extract probe is `<?php class C { function __destruct(){ echo 'D'; } } function f(){ extract(['o' => new C]); } f(); echo 'A';` and previously produced `AD` on the walker, against the hand-derived `DA`. PHP 8.3 is unavailable locally; the orchestrator was asked for the exact oracle. The array-literal lowering does not register the resulting counted array as a statement temporary, even though `array-put` adds a reference to a counted element: this is a plausible ownership leak, not a proven complete cause. Do not claim the issue fixed or the expected output confirmed.

Validation: `generator-fixtures-on-every-vm-test` passed 60 assertions with the subsequently withdrawn completion trial present (a 120-second attempt timed out; the successful attempt had a 600-second timeout). `lower-portable-test` passed 8 tests / 1254 assertions with that trial present, also under 600 seconds; neither result is a post-withdrawal gate. The accessor test passed 8 assertions with a 180-second timeout. The post-withdrawal scope cleanup test passed 3 tests / 6 assertions under 180 seconds. PHP 8.3 fixtures remain `:oracle :pending`.

The bridge remains incomplete: request/response transport and service-backed admission/publication, caller-task `php/eval-run` including scope/budget, both expression routes, atomic guest compile fatal, real-service fixtures and the full gate set remain outstanding. The standalone publisher is not an admission decision. No end-to-end eval support is claimed. Node/Dart and lint validation remain outstanding.
