## 2. What Has Been Implemented

1. **Host Modules Registered in REPL VM**:
   - [`src/cljc/yin/repl.cljc`](file:///Users/sto/workspace/datomworld/src/cljc/yin/repl.cljc): `make-vm` registers `cell`, `data`, and `integer` host modules with identical resource limits (`max-bits 100000`, `max-digits 4300`, `max-items 1048576`).
2. **REPL Completeness Probe Support**:
   - [`src/cljc/yin/repl.cljc`](file:///Users/sto/workspace/datomworld/src/cljc/yin/repl.cljc): `eval-input` queries the binding's `:probe` if present. If `:probe` answers `:incomplete`, indentation is preserved and text is buffered in `:pending-input`. A blank line closes an indented block. Falls back to `bracket-balance` for frontends without `:probe`.
3. **Session State Persistence (`__main__`)**:
   - [`src/cljc/yin/repl.cljc`](file:///Users/sto/workspace/datomworld/src/cljc/yin/repl.cljc): Frontend bindings can declare `:lower-session [parsed session-marker] -> [ast session-marker']`. The session marker is tracked on the REPL state as `:frontend-session` and cleared on `(reset)` / `(vm ...)`.
   - [`src/cljc/yang/python/antlr/repl.cljc`](file:///Users/sto/workspace/datomworld/src/cljc/yang/python/antlr/repl.cljc) (new, portable): Wraps `lower-module-body` to run against `sys.modules["__main__"]`.
   - The bundled prelude is prepended **only on the first submission** of a session (transitioning state to `:primed`). Subsequent submissions reuse the existing VM store and `__main__` namespace, preventing state loss and avoiding duplicate execution of `py/init!`.
   - Output and uncaught exceptions are rendered via host primitive `py-report` and printed to the shell's output medium.
4. **ANTLR Completeness Probe**:
   - [`src/clj/yang/python/antlr/repl_probe.clj`](file:///Users/sto/workspace/datomworld/src/clj/yang/python/antlr/repl_probe.clj) (new, JVM): Checks open bracket balance, parses with trailing newline to inspect ANTLR syntax errors (EOF / INDENT expectations), and treats indented blocks as `:incomplete` until closed by a blank line.
5. **Catalog Registration**:
   - [`src/cljc/yin/repl/frontends.cljc`](file:///Users/sto/workspace/datomworld/src/cljc/yin/repl/frontends.cljc): Registers `:yang.python/antlr` (language `:python.antlr`, revision `"f3"`) on JVM only.
   - Uses `#?@(:cljd [] :clj ...)` reader conditionals to prevent ClojureDart from attempting to compile JVM ANTLR parser classes.
   - Parse stage appends `\n` to incoming source units so bare statements parse cleanly.
6. **Tests**:
   - [`test/yin/repl/python_antlr_test.clj`](file:///Users/sto/workspace/datomworld/test/yin/repl/python_antlr_test.clj) (new): 5 comprehensive tests covering `x = 1` then `print(x)`, multi-line `def` buffering, open brackets, `(reset)` process restart, and exception retention.
   - [`test/yin/repl/frontend_catalog_test.cljc`](file:///Users/sto/workspace/datomworld/test/yin/repl/frontend_catalog_test.cljc): Updated to use `:yang.python/uninstalled` and `:yang.python/service` so tests assert unavailability properly across all hosts without colliding with the real registered ANTLR frontend on JVM.
