The macro namespace's own initialization precedes the guard; the guard does not cover other possible paths. One run passed **1 test, 6 assertions, 0 failures, 0 errors**. The process and temporary files were removed on exit. Run with `python3 test/yang/correspondence_snapshot_probe.py` only where the named scratch inventory and objects remain available. Probe SHA-256: `6921fffdafacaf7b20055526fd37639336ae9683e61447a0696b4c5c03f931a9`.

This is more constrained than the r23 local-path probe: Java and the classpath arguments point to verified restored snapshots, and the working directory is temporary. It is **not an OS sandbox**: the process could still read the checkout, caches, host files and facilities, and no syscall audit proves otherwise. The Python bootstrap, expression and inventory locator are outside a retained execution manifest. JVM defaults and host facilities are not fully declared or constrained. The r18 snapshot predates later edits and is not shown identical to the current entire source tree. It is not a durable package, and its hashes are not a published execution-manifest/profile identity.

The test makes a **fresh** `:beta-eq-false` admission and derives its expected results within the same process; it then compares its captured input and results through the producer-side close/reopen check. It does not fetch a previously retained corpus admission or independently reconstruct fixture adaptation from verified context sources, and it shares producer machinery for classifications and correspondence. Consequently the passing result is not the ruling's retained-input-to-claimed-output isolated replay. The guarded run demonstrates only that the two instrumented Vars were not invoked in this execution after they were armed; it does not prove the complete pinned composition bypass or historical behavior.
