## Enforcement and baseline work

`test/yang/correspondence_lane.clj` now reports max printed-record bytes and can invoke an explicit per-step runtime check. `yang.correspondence-measure/runtime-checker` checks steps, monotonic elapsed time, observed process used heap and current ring record positions, refusing missing trace handles, evicted prefixes or a declared maximum exceeded. It checks at step boundaries, so it is a sampled used-heap limit, not an operating-system memory cap or a bound on a single host operation; a complete bounded driver still needs to wire it in and record all refusal evidence. Red-first tests cover a runtime cutoff and exceeded time, heap and record limits. A trace-free source preparation helper checks the entire captured oracle suffix, preserving the already-assembled library prefix and refusing assembly or collection-order/metadata fidelity mismatches; it does not invent a new retained origin. Its negative tests were observed red first.
