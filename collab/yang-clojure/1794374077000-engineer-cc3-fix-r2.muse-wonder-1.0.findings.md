## Per-finding disposition

### 1. P1 — stamped paths ≠ pre-stamp paths (latte_oracle_test.clj) — FIXED

- `test/yang/latte_oracle_test.clj:3479` `cc3-correspond`: the explicit
  stamped→pre-stamp transformation mapping. Both trees are traversed
  together in grammar positions; recognized stamping wrappers
  (`kernel-stamped-args?` — the three applications a stamp inserts around
  an argument node) are removed by descending to the wrapped argument at
  `operands[0]/operands[1]/operands[2]`. A type mismatch, a child-count
  mismatch, a wrapper over a pre-stamp wrapper, or a site with no
  correspondence refuses with `:rule :cc3-stamp-correspondence`; two
  sites mapping to one occurrence refuse with
  `:rule :cc3-ambiguous-stamp-correspondence`. A mapped key that is no
  validated C1 occurrence also refuses at binding time.
- `cc3-oracle-binding` (`:3555`) now combines the PRE-STAMP root only
  with correspondence-translated paths, and returns `:correspondence`
  and `:stamped-paths` as evidence.
- Tests: `test-cc3-stamp-correspondence-nested` (`:3799`, synthetic: a
  guest call nested inside another stamped call's argument vector really
  moves — pre-stamp `[[3 1] [3 1]]` vs a longer stamped path — and maps
  back to its own application; divergent trees refuse), plus the
  binding deftest's correspondence assertion for every bound site.

### 2. P1 — synthesized origin from content (latte_oracle_test.clj) — FIXED

- `kernel-compile` records the admission coordinate WHEN ADMITTING the
  fixture (`test/yang/latte_oracle_test.clj:2451` counter, `:2472`
  record): the batch token is `<canonical-source-hash>#admission-<n>`
  with `n` the harness's sequential admission ordinal, retained with the
  compilation as `:admission-origin`. Identical content admitted twice
  is two histories with two origins; the content hash alone is never the
  origin.
- `cc3-oracle-binding` consumes ONLY that retained record: a compilation
  without one refuses with `:rule :cc3-admission-record`; no new envelope
  is synthesized post-compilation, and `[:oracle/fixture <id>]` is still
  never minted.
- Tests: the binding deftest pins origin = retained record, origin ≠
  content-only coordinate, missing-record refusal, and replay (rebinding
  one retained compilation answers the identical binding).
  `test-cc3-distinct-admissions-distinct-origins` (`:3837`) pins two
  admissions of identical content (same canonical hash) carrying
  distinct origins, with the same sites bound under each admission's own
  origin.

### 3. P1 — root-only lookup borrows across admissions (repl.cljc) — FIXED

- `packet-call-provenance` (`src/cljc/yin/repl.cljc:172`) is now
  `[state packet admission]`: it requires the packet's retained
  admission identity, validates it (`:rule :call-site-admission` for a
  malformed identity), and selects the retained table by

  (`test/yang/clojure_callsite_test.cljc:2013`): claimed-A/unclaimed-B
  with an identical root — B answers nil; two retained admissions for
