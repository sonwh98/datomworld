- [src/cljc/yin/repl.cljc:1270](/Users/sto/workspace/datomworld-cc2/src/cljc/yin/repl.cljc:1270): `record-call-site-admissions` pairs only programs ABSENT from `:programs-before` — the entities the current round's successful commit actually committed. Absent/unreadable evidence (`nil` programs-before/after, missing evidence) records nothing.

Multiple admissions or multiple candidates for one root refuse all of them (unmapped, claim-free publication) — never first-wins. No counter is read or compared anywhere.
- [src/cljc/yin/repl.cljc:1238](/Users/sto/workspace/datomworld-cc2/src/cljc/yin/repl.cljc:1238): `indexed-program-roots` now answers `[]` (not nil) when nothing is published yet, keeping "empty index" distinct from "unreadable index" (nil, fail-closed).
