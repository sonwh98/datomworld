# J7 Engineer Implementation Findings

## Overview

Implemented Slices 1 and 2 per the architect's committed design (`collab/jolt/1794773141000-architect-j7-design.findings.md`).

### Slice 1: Value Channel Factoring, CSPRNG Lowering, and Native Datagram Seam
1. **Value Channel Factoring (`src/cljc/dao/stream/udp/common.cljc` and `src/cljc/dao/stream/udp.cljc`)**:
   - Factored all host-free value channel functions into `dao.stream.udp.common`: constants (`transport-type`, `max-datagram`, `default-max-message-bytes`, `default-max-partial-messages`, `default-step-budget`), packet validation (`descriptor?`, `address-key`), fragmentation and reassembly (`make-port`, `send-value!`, `send-to!`, `receive!`), projection (`projection`, `step!`, `reading-cursor`), and raw ring processing (`port-step!`).
   - Retained public facade `dao.stream.udp` on every host exposing the full existing public surface, `UdpHandle` type, and `make-attacher` delegating to `dao.stream.udp.common`.
2. **CSPRNG Lowering (`src/jolt/dao/posix/random.jolt` and `src/jolt/yin/vm/linker/random.jolt`)**:
   - Lowered the qualified libcrypto CSPRNG draw implementation (`jolt_crypto_random`) to `dao.posix.random`.
   - Updated `yin.vm.linker.random` to delegate `rand-bytes` to `dao.posix.random/rand-bytes`, removing any `yin.*` dependency from `dao.space.dht`.
3. **Native Datagram Host Seam (`src/jolt/dao/stream/udp.jolt`)**:
   - Implemented production datagram socket creation over `jolt.socket.native` and `jolt.ffi` using `SOCK_DGRAM` (2) and `IPPROTO_UDP` (17).
   - Ensured nonblocking mode, close-on-exec, IPv6-only option (`IPV6_V6ONLY = 1`) on IPv6 sockets, and strict literal IP parsing without DNS or localhost.
   - Synchronously deposits `:dao.stream.datagram/bound` with bound port and address before returning from `bind!`.
   - Bounded receive turn `:step!` reading up to 64 datagrams using `(inc max-bytes)` buffer; correctly drops oversize packets via sentinel and deposits `datagram-event`s with Base64 encoding.
   - Immediate `sendto` syscall with dynamic `*sendto*` indirection for fault injection; failures immediately report `:dao.stream/transport-error` and deposit `:dao.stream.datagram/send-failed`.
   - Safe, idempotent `close!` canceling and forgetting poller registrations before closing fd, depositing `:dao.stream.datagram/closed`.

### Slice 2: Shared DHT Host Composition and Shell Activation
1. **Host Composition (`src/cljc/dao/space/dht.cljc`)**:
   - Added `:jolt` reader conditional branch to namespace requirements importing `[dao.stream.udp :as datagram.host]` and `[dao.posix.random :as posix.random]`.
   - Added `:jolt` arms to `default-bind` and `secure-random-bytes`.
   - Added explicit seam servicing `(when-let [step-fn (get-in node [:seam :step!])] (step-fn))` in `dao.space.dht/step` before ticks and DHT processing.
2. **Board Codec & Refusal Removal (`src/cljc/yin/shell/dht.cljc`)**:
   - Set head board dial profile to CBOR (`(:cbor connect/codec-profiles)`) and served profiles to CBOR first plus Transit where supported.
   - Removed the unconditional jolt refusal at lines 255–257, allowing solo and networked DHT stores to compose on jolt.
