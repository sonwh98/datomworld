# Review: jolt host-lane plan r5 (independent, Architect review flavor)

Reviewer: claude-opus-5-5. Independent of the GPT-authored plan. I did not author or implement any of it.
Under review: `collab/1792425503000-architect-jolt-lane-plan-r5.gpt-6-astra.findings.md`.
Context (not redone): Fable r1 review, the spike report, jolt checkout `build/jolt-spike/jolt` (I did not run git there; HEAD was confirmed by Fable r1 as `96d7b866…`), `docs/design/datom.world.md`, `yang.antlr.md`, `antlr/python3/manifest.edn`, `src/{clj,cljc}/yang/antlr/*`, `src/cljc/dao/stream/datagram.cljc`.
Method: I read every new r3–r5 citation at its cited lines. I ran nothing: no builds, no probes, no sysctl. No network, so the official ANTLR documentation claims stay R. The only file written is this one.

## Verdict

**APPROVE WITH CHANGES.**

The decision structure holds up: one shared-source lane, no forked engine, no second codec, engine §E.5 as the only oracle, honest milestone labels, and every claim marked S/V/R/P. The r3–r5 socket and poller citations are accurate. Four material defects need fixing before anything is commissioned:

- **R1.** The C++ parser design moves the host-free CST export into C++, along with a C++ Jing encoder. That breaks the existing per-host exporter pattern.
- **R2.** It ignores the requirement in yang.antlr.md §4.3 that each worker owns its recognizer caches. ANTLR C++ keeps them in hidden global shared state.
- **R3.** The UDP probe writes a `:full` outcome into J0 acceptance. The landed datagram contract excludes `:full` by design, and the owner wording on record does not cover it.
- **R4.** On macOS, "system/Homebrew libcrypto" can abort the process before the planned version check ever runs. jolt's own tree records this.

J0 is also too large to be one falsifiable first commission (R7).
