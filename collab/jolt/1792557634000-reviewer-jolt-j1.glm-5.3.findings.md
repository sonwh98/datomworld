## Verified clean (adversarial checks that did not find defects)

- **Laws beyond the tests.** `utf8-decode` is a strict RFC 3629 decoder written
  out (Unicode table 3-7 boundaries checked by reading: C0/C1, E0 A0, ED 80-9F,
  F0 90, F4 8F, F5-FF, truncation, stray continuation, BOM as content) — Chez's
  substituting `utf8->string` is not used. `parse-decimal` keeps the shared
  grammar verbatim before any host parser (jolt's reader accepts `1_000`; the
  grammar refuses it first — r11 cases equal on both hosts). `to-radix-string`
  lowercases Chez's uppercase. `decimal-of` uses `BigDecimal/valueOf`, never
  the scale-dropping constructor, and the big-mantissa compare case passes.
  Float bits go through a Chez bytevector (jolt design §5.2), every NaN
  7ff8000000000000, including signaling-payload round trips. Table B's kernel
  is byte-identical to the shared file (diff leaves only ns/docstring and the
  Table A hunks). `bytes/copy!` prevalidates both ranges before any write and
  memmoves backward only when the destination starts after the source; M
  entries return nil; slice/from-vector/alloc/magnitude-bytes/utf8-encode are
  fresh.
- **Broken bit functions.** No jolt `bit-and`/`bit-or` beyond 2^32 anywhere
  (grep over all new files); all big bit ops go through Chez `logand`/`logor`/
  `logxor`/`ash`, exact on bignums; `shift-right-big` = `ash a (-k)` is floor,
  equal to BigInteger semantics (compare covers negatives and counts 0..128).
- **Scheme interop.** Only `scheme/proc` with literal names and two constant
  `eval-string` lambdas; no data-driven Scheme evaluation.
- **Runner honesty.** Counts per namespace from jolt's clojure.test counters;
  nonzero exit on any fail, error or load failure; the self-test proves a
  throwing test is one error and the batch continues (`r2-runner-self.log`,
  order `[before-the-throw throws after-the-throw]`); explicit namespace list,
  no scanning; the sentinel lives only under src/dev.
- **Stand-in loader.** Supplies exactly the four functions the two tests call
  (grep of float/text tests confirms: `read-path`, `cases-of-kind`,
  `hex->ints`, `read-path` again), with code identical to the real `:clj` arm;
  it cannot make conformance-test load (that requires `dao.jing.cbor`
  directly) and is labelled diagnostic in the task and docstring. The corpus
  reaches jolt through the shim, whose 54 assertions pass on both hosts
  (`r2-json-test-jvm.log`: real data.json 2.5.0, 7/54).
- **Isolation of the shim.** `src/jolt` is absent from every default path
  (`deps.edn:22`), and `.jolt` is not a resolvable extension for JVM/CLJS/Dart
  compilers — double protection; the shim cannot load on another host.
- **Scope.** Unstaged diff = `.cljstyle`, `bb.edn`, `deps.edn`,
  `src/jolt/README.md` only; nothing under src/cljc, test/dao/host, src/clj,
  docs/design or the host-boundary files; `.cljstyle` change is one added
  extension.
- **Logs corroborate the reports firsthand.** `r2-diag.log` SUMMARY
  {10 tests, 145 assertions, 133 pass, 8 fail, 4 error} with DETAIL lines all
  surrogate-stop or `(Runtime/version)`; `r2-oracle.log` 3 boring/core load
  failures, bytes 6/98 pass; `compare.diff` = 72 changed lines = 36 differences
  in exactly the four reported classes (28 carrier tags incl. Integer-vs-Long
