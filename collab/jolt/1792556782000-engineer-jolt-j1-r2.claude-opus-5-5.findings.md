## 2. clojure.data.json (step 2)

### 2.1 What the repository calls

`grep` over `test/dao/host/*_test.cljc` and the fixture helper: the host tests never require `clojure.data.json` themselves. Its only require is `test/dao/jing/cbor_fixtures.cljc:17` (`:clj` arm), and the only call sites are:

- `:69` `(json/read-str (json/write-str (json/read-str text)))` in `json-round-trip`.

Neither `:key-fn` nor `read` is used anywhere.
- The shim supports `read-str` with `:key-fn`, because the brief named it, and `write-str`.
- `read`, `write` and every other option are absent, and an unsupported option throws instead of being ignored.

### 2.2 The shim

- **File:** `src/jolt/clojure/data/json.jolt`. The `.jolt` extension means no other host can load it.
- **How jolt finds it.** On jolt it is found in `src/jolt` before any jar; the `:jolt` alias fetches no deps. A probe confirms the loaded namespace has the shim's private `json-error`: `build/j1-logs/r2-load-chain-no-boring.log`, "clojure.data.json from shim: true".
- **Behaviour** follows what data.json 2.5.0 does on the JVM, observed before writing it:
  - numbers: exact integers, a BigInt past 64 bits, a double for a fraction or exponent; strict number grammar (`01`, `1.`, `.5`, `+1`, `1e` refused); `-0` reads as 0;
  - strings: every escape, including surrogate pairs; raw control characters accepted;
  - objects: the last duplicate key wins;
  - text after the first value is ignored;
  - `write-str` escapes all non-ASCII as `\uXXXX` (an astral character as its surrogate pair), and `/` as `\/`.
- **The one difference that cannot be removed:** an unpaired-surrogate escape (`"\ud800"`) throws `:jolt/unimplemented`. The JVM builds a 1-unit string. This is the same Chez limitation as the round-1 stop. The cbor-v1 corpus has no such escape.

### 2.3 Tests of its own

Twenty-one malformed inputs must throw: `""`, `"   "`, `[1,2,]`, `01`, `1.`, `.5`, `+1`, `1e`, `NaN`, `nul`, `tru`, an unterminated string, `\x`, `\u12`, a missing `:`, a non-string key, unterminated object and array, a missing comma, a trailing comma in an object, `-`, a stray `}`.

## 4. jolt bugs: minimal reproductions (not filed)

Both are run from an empty directory (`/tmp/jolt-repro-j1`, no `deps.edn`) with jolt 96d7b866 (`jolt-toolchain.edn` pin) on Chez 10.4.1, macOS arm64.

### 4.1 `(java.math.BigDecimal. BigInteger int)` ignores the scale and builds the wrong value

```
$ jolt -e '(let [d (java.math.BigDecimal. (biginteger 15) 3)] [d (.scale d) (.unscaledValue d) (.scale (java.math.BigDecimal/valueOf 15 3))])'
[15M 0 15 3]
$ clojure -M -e '<same form>'        # JVM, Clojure 1.12
[0.015M 3 15 3]
```

- **Expected (JDK):** `BigDecimal(BigInteger unscaledVal, int scale)` is `unscaledVal × 10^-scale`, so 0.015 with scale 3.
- **Cause:** jolt's shim `host/chez/java/bigdec.ss` `jbd-class-ctor` is `(define (jbd-class-ctor x . _) ...)`. It drops every argument after the first and builds `(jolt-bigdec x)`, which is 15 with scale 0.
- **Not affected:** `BigDecimal/valueOf (unscaled, scale)` is correct; the J1 number override uses it.

### 4.2 org.clojure/data.json 2.5.0 does not load

```
$ jolt -Sdeps '{:deps {org.clojure/data.json {:mvn/version "2.5.0"}}}' -e "(require 'clojure.data.json)"
Unhandled exception (IllegalArgumentException): No dependency provides java.time.format.DateTimeFormatter — a concrete implementation of the JDK classes must be provided. A library supplies one by declaring :jolt/provides in its deps.edn (RFC 0014).
  at jar:file:~/.m2/repository/org/clojure/data.json/2.5.0/data.json-2.5.0.jar!/clojure/data/json.clj:785:1
$ clojure -Sdeps '<same deps>' -M -e "(require 'clojure.data.json) (clojure.data.json/read-str \"[1]\")"
[1]
```

- **Cause:** `json.clj:785` `(def default-write-options {... :date-formatter java.time.format.DateTimeFormatter/ISO_INSTANT ...})` (`json.clj:789`) is evaluated at load time. Evaluating it needs the class, which jolt has no shim for (`jolt -e '(java.time.format.DateTimeFormatter/ISO_INSTANT)'` fails the same way). So even `read-str`, which never formats a date, is unusable.
- **Possible upstream fixes:** a minimal `DateTimeFormatter/ISO_INSTANT` shim, or lazy resolution of the class token in a def that is never called.
