## Edits

- `src/cljc/dao/stream/remote.cljc`
  - `write-answer!` returns the writer's outcome (the oversize replacement's outcome when the first append answered `invalid-value`).
  - `answer-named!` and `answer!` return the writer's outcome. `answer!` takes `chase-max` and runs the chase with `(if chase-max (min k chase-max) k)`, only when the request has a valid budget.
  - `mirror-step` gets a 6-arity `(table names chan-reader cursor chan-writer bounds)`; the 4- and 5-arities delegate with `bounds nil`. Bad bounds throw `ex-info "invalid DaoStream remote mirror bounds" {:bounds bounds}`: a non-nil non-map, or any non-nil value that is not a positive integer. The loop counts `mirror-budget` down on each `ok` (well-formed or malformed) and on each `gap`. At zero it returns the current cursor. `blocked`/`end` cost nothing.
  - Rewind on `full`: when the writer answers `:dao.stream/full` and the request's op is not `:dao.stream/append!`, the step returns the cursor before that request. This covers descriptor, cursor, next and named descriptor. A `full` on an append! answer is dropped and the step continues.
- `src/cljc/dao/stream/ws_project.cljc`
  - New private helpers: `pos-int-or-nil?` and `mirror-bounds`, which builds the `:dao.stream.remote/*` bounds map from state.
  - `make-acceptor` accepts, validates (inside the existing `when-not`) and stores `:mirror-budget`/`:chase-budget`. `accept-step!` passes `(mirror-bounds @acceptor)` to the 6-arity.
  - `dial` accepts, validates and stores `:step-budget`/`:mirror-budget`/`:chase-budget`. `dial-step!` calls `(step! project step-budget)` and passes the bounds map to the mirror.
  - Docstrings updated.
- `docs/design/dao.stream.remote.md`: §2.3 documents the 6-arity, the bounds map and validation, the counting rule for `mirror-budget`, the `chase-budget` clamp, and the `full` rewind/drop rule. §3.0's step-budget bullet now names `:mirror-budget`/`:chase-budget` for the acceptor and the three keys for the dial.
- Tests:
  - `remote_test.cljc` gains `mirror-budget-bounds-requests-per-step`, `malformed-values-and-gaps-count-against-the-mirror-budget`, `an-invalid-mirror-bound-is-a-composition-error`, `chase-budget-clamps-a-peer-requested-budget` and `a-full-writer-rewinds-idempotent-answers-and-drops-append-answers`. The last one covers identity descriptor, named descriptor and append!.
