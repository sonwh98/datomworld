1. **`src/cljc/dao/stream/remote.cljc`**:
   - **`mirror-step` 6-arity**:
     - Signature: `(mirror-step table names chan-reader cursor chan-writer bounds) -> cursor'`
     - 4- and 5-arities delegate with `bounds nil`:
       `(mirror-step table chan-reader cursor chan-writer) -> (mirror-step table nil chan-reader cursor chan-writer nil)`
       `(mirror-step table names chan-reader cursor chan-writer) -> (mirror-step table names chan-reader cursor chan-writer nil)`
     - `bounds` is `nil` or a map containing optional:
       - `:dao.stream.remote/mirror-budget` (positive integer or nil)
       - `:dao.stream.remote/chase-budget` (positive integer or nil)
     - Validation: when `(some? bounds)`, throw `(ex-info "invalid DaoStream remote mirror bounds" {:bounds bounds})` if `bounds` is not a map or if any non-nil value in it is not a positive integer.
     - Budget loop: decrements on `:dao.stream/ok` (well-formed or malformed) and on `:dao.stream/gap`. Stops when remaining reaches 0, returning the current reading cursor (preserving continuation state). Blocked and end are free.
     - **`chase-budget` clamp**: In `answer!`, clamp effective chase budget `k` with `(if chase-max (min k chase-max) k)`.
     - **Writer backpressure & rewind**:
       - `write-answer!` returns the writer's outcome.
       - In `mirror-step`, if `write-answer!` answers `:dao.stream/full` for an idempotent operation (`descriptor`, `cursor`, `next`, or named `descriptor`), stop the step and return the cursor *preceding* that request so it can be re-attempted next tick.
       - A `full` on `append!` answer does not rewind (source append already ran; re-applying would duplicate; answer dropped per 2.5).
