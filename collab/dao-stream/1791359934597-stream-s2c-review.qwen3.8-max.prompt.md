### Core Behavioral Requirements for S2c:
1. **Policy & Configuration**:
   - `:dao.stream.remote/give-up-after` validated as positive integer or nil.
   - Propagated through `dial` options into remote links.
2. **Deadline Stamping**:
   - `new-deadline`: `now + give-up-after`, or `nil` if either is missing.
   - Stamped when request first exists on the link (accepted writes, kept probes).
   - Resends (`count-ask!`) must NEVER advance/modify `:deadline`.
   - Probes waiting on reflection (`:probe` state from S2b) do not stamp until admitted onto the link.
   - Answers clear the outstanding request along with its deadline.
3. **Link Step & Channel Expiry**:
   - Exposes `:step` on `links` as `(step cd now)`.
   - Drains incoming values (respecting `drain-budget`).
   - If `:channel-gone?` is not already true, scans outstanding and pending entries for lowest ID with `:deadline <= now`.
   - Emits `{:dao.stream.remote/event :dao.stream.remote/channel-expired :dao.stream.remote/id id :dao.stream.remote/op op}`.
   - Invokes `channel-loss!` (abandons outstanding requests, emits `append-unknown`, marks channel gone).
   - Returns `{:dao.stream.remote/channel-gone? bool :dao.stream.remote/expired id-or-nil}`.
4. **WebSocket Dial Integration**:
   - `dial-step!` supports multi-arity: `([dial] (dial-step! dial nil))` and `([dial now])`.
   - When stepped with `now`, steps link with `now`. If link reports `channel-gone? true`, closes the underlying ws socket handle.
   - `establish!` steps a newly created link with dial's last known `now` before sending attach probe to ensure attach probe is stamped.
