## 5. Rulings on the engineer's deviations

The architect's cancellation case (−(2⁶⁰−1), 2⁵⁹, i=2 → 1) is pinned in `range-small-profile-test` and passes; a breach legitimately means a never-yielded out-of-budget candidate, answered `:py/stop` per the ruling. The deviation is simpler than the ruled design and equally sound.
3. **`:small?` on the runtime range map, computed once.** APPROVE. The snapshot copies only start/stop/step into `:py/range` (`prelude.cljc:2155–2160`) and the renderer reads only that (`render.cljc:127–130`), so no output, golden, or row shape changes; a range lacking the key (older data) is falsy → exact path, which is the safe default.
4. **Slow/guard tagging + parser batching.** APPROVE. Every row runs in both corpora; the Dart RangeError rationale is a program-size limit, not evasion; the fast portable tests still exercise all carrier hazards on every host in the changed lanes.
5. **Products replacing `3**40`/`1<<54` in the flipped tests, pending ops left pending.** APPROVE. The expected strings are fable §6 verbatim; nothing half-implements B/C operators.
