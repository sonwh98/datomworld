# Product: Datom.World

## What is Datom.World?
Datom.World is a sovereign, post-web computing paradigm built entirely on **immutable tuples** and **continuous streams**. It decomposes the legacy web stack (JS VM, HTTP, DOM, LocalStorage) into universal primitives:
- **Yang**: Universal AST compiler frontend (Clojure, Python, PHP into AST datoms).
- **Yin VM**: CESK continuation machine family (mobile, serializable, sandboxable computation).
- **DaoStream**: Stream transport foundation modeling all IO as streams.
- **DaoJing**: Content-addressed immutable datom segment storage.
- **DaoSpace**: Tuple space for multi-agent stigmergic coordination and Datalog queries over streams.
- **PostGraphics**: Frame program vocabulary executed by terminals (Flutter GPU, canvas, WebGPU).
- **Shibi**: Capability tokens for anti-spam economic regulation without censorship.

## Audience & Users
1. **Distributed Systems & Language Engineers**: Building next-generation continuation machines, compilers, and streaming runtimes.
2. **AI Agent Architects**: Building collaborative multi-agent systems where agents share durable, queryable episodic memory and coordinate via stigmergic fact spaces without opaque session caches.
3. **Decentralized Protocol Builders**: Creating sovereign spatial networks and verifiable infrastructure.

## Key Brand & Aesthetic Character
- **Philosophy**: Ancient Daoist computational aesthetics ("One truth, many perspectives", Yin & Yang, effortless flow) fused with cutting-edge theoretical computing (CESK continuation machines, Universal ASTs, moduli spaces, Datalog, content-addressed storage).
- **Voice**: Rigorous, visionary, poetic, deeply technical, devoid of generic modern SaaS clichés.
