## Ambiguities resolved (minimal readings)

1. **Channel context identity**: derived per call from the chan-reader's `descriptor` `:dao.stream/identity` — the attachment the request arrived on (the spec names the key, not its source).
2. **Budget minting**: the spec fixes the wire key but not who mints it; the link composes the requests, so `:dao.stream.remote/budget` is attacher composition data stamped on every `next` request. Absence is always correct ("a mirror that ignores the budget is correct").
3. **Oversize granularity**: step 4 is one append of the whole answer including `:more`; on `invalid-value` the oversize error replaces that one channel value and no chase result beyond it is delivered. Any other refused mirror write (full/closed) leaves the request unanswered and the step continues.
4. **Channel-reader gap** (mirror and link): adopt the reader's own recovery cursor and stop; lost wire values are lost, resend recovers requests.
5. **Filing scope**: a filed answer keeps its request and its reflection — an answer belongs to the operation that caused it (refusal is per operation), so reflections on one link never consume each other's answers; `:more` installations stay link-level shared positional truth. `cursor` filings are kept (the spec says "forgotten" only for `next`); `outstanding-for`/`filed-for` both correlate per (reflection, op, arg).
6. **Probe resend cadence**: each drain counts as the one further ask for an outstanding descriptor probe (no caller ever asks descriptor remotely); resends reuse the same id.
7. **append! answers** (ordinary or error) are emitted on the event writer, never filed; the probe's no-surface/oversize errors mark nothing and are dropped.
8. **Precedence**: after `close!` the closed contract governs; while open, gone beats everything but descriptor; learned no-surface answers locally before any send; channel-gone only after filed lookups ("filed answers are still returned").
9. **Verbatim return**: the envelope's correlation keys (`:dao.stream.remote/id`, `:dao.stream/identity`) are stripped so the caller receives the source's outcome map itself.
10. The reflection implements all four protocols (the surface is learned only from the probe); the learned surface reproduces the translated no-surface answer exactly. No `dao.stream.md` change was required — the deferred-confirmation clause and `:dao.stream/refused` were already in the contract.
