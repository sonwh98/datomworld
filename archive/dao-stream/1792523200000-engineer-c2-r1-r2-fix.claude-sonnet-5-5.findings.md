## R2
New `test/dao/stream/ws_project_corpus.cljc`: a 24-value subset of the §4.4 envelope corpus plus one Jing payload wrapped by `jing-stream/wrap-payload`, served as "str-3".
- Plain values: nil, booleans, strings (incl. unicode), ints through ±max-safe, doubles 1.5 and 0.001, keywords, symbols, vectors, a set, maps and a nested map.
- Excluded: baseline-exception values (lists, integral doubles, metadata). They remain covered by the frozen fixtures.
- Comparison is `=` after the Jing bytes are unwrapped to octets.
- The peer (`ws_project_peer.cljc`) serves "str-3" in both roles. `:attach` accepts `:identity`. `:read` replies are normalized so CBOR host bytes never go through the Transit stdout line.
- `ws_project_cross_node_test.cljs` adds 4 tests, each run for Transit and CBOR:
  - JVM serves, Node dials and decodes the corpus.
  - Node serves, JVM dials and decodes.
  - The JVM dial-side mirror serves back over the same session, and Node decodes.
- Each corpus chain asserts the count and the per-value equality, including the Jing payload.
- Each attach needs its own dial and peer (one attachment per dial), so the corpus chains are separate tests. They are not appended to the existing toy chains.

Gaps, stated plainly:
- "Old peer" is the other host's code (JVM vs Node), not the F0-tagged tree. No old-tree process was built.
- Node serving to a JVM dial that reflects back is covered. Node dials and JVM serves covers only the server→dialer direction. There is no Node-side reverse reflection in that chain.
- Dart is not covered and stays an absent-coverage gap under §7.3.
- The JVM-only cross test (`ws_project_cross_jvm_test.clj`) drives only the Dart peer and was not extended.
