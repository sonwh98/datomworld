**Ruling (a): accept the explicit stage-budget extension, with a documented amendment.**

At `lower.cljc:1623`, a stage budget fills only an absent packet key; a packet declaration wins. With neither declaration, decimal values above 2^53−1 produce an unsupported source diagnostic. Declared decimal budgets count digits after underscore removal; power-of-two source radices are exempt.

This introduces no implicit numeric default. It does extend the binding design’s stricter packet-only wording: an incoming packet without a budget can now compile under an explicitly configured composition. That extension is reasonable and pinned by precedence tests. Document it in the binding design.

A source diagnostic remains the correct result when no effective budget exists or a decimal token exceeds it. It is a profile restriction, not CPython 3.9.6 behavior. Invalid budget configuration appropriately remains a composition error.

**Ruling (b): accept the admission floor and its vocabulary.**

`prelude/register-integer-module` is the appropriate Python composition boundary; the general integer module must continue allowing smaller profiles. The 53-bit floor protects all inline literals. The 60-bit profile remains admissible.

The Python-qualified refusal identifies a profile-admission failure. It differs from integer export refusals and the module’s `::reason :limits` configuration error, but does not masquerade as either. No vocabulary change is required; broader use of the wrapper is recommended.

**Ruling (7): retain S2 as an integration slice; do not ship its unrestricted behavior alone.**

“Nothing deployed; S3 follows immediately” permits an intermediate commit, but does not make this runnable state safe to release. Prefer joint release with S3-A/B/C, covering every still-exposed operator.
