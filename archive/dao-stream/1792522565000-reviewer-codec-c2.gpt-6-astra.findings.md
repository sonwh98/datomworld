## Blocking findings

### R1 — Migration misses indirect host calls; grep gate does not pass

`test/yin/repl/host/jvm_test.clj:100` invokes `((:bind! adapter) ...)` without `:codecs`. Although its endpoint and attacher now name Transit, `yin.repl.host.jvm/websocket` exposes `jvm/listen!` directly; that listener reads its own options and falls back to `default-codecs` (`src/clj/dao/stream/ws/jvm.clj:423`). An endpoint's profile does not supply that missing option.

The untouched `test/yin/repl/host/node_test.cljs` has the same omission at lines 38, 108 and 127. Its direct `((:connect! adapter) ...)` at line 57 also supplies no `:ws/codec` in the adapter map. `src/cljs/dao/stream/ws/node.cljs:210` consequently uses the legacy `ws/subprotocol` fallback. The updated Node REPL binder forwards a nil `:codecs` for these callers, and `node/listen!` still resolves that to its default.

These are unintentional dependencies on defaults that C3 is commissioned to remove. The engineer's `/tmp/c2tool/gate.py` scans named `jvm/listen!`, `host/bind!`, etc.; it misses map-dispatched calls. I reran that scanner and independently expanded the search to `(:bind! ...)` and `(:connect! ...)`, exposing these five omissions.

Required change: supply `[transit/profile]` to all four bind calls and `:ws/codec transit/profile` to the direct Node connection adapter (or another explicitly matched profile). Extend the gate to cover indirect seams, and run the JVM and Node host tests. C2's premise that C3 can remove defaults without breaking migrated callers is not yet true.

### R2 — Required §7.3 live corpus/Jing proof is missing

`test/dao/stream/ws_project_peer.cljc:289,393` constructs toy streams carrying `"backward"` and `"hello"`. The cross-node proofs and `/tmp/c2tool/jvm_pair.py` check toy reads, probe/lifecycle and reflection behavior. They do not exchange the envelope corpus in both directions or a Jing-wrapped payload. The engineer report expressly acknowledges this gap.

§7.3 requires both frozen fixtures and live old/new corpus exchange. Passing frozen decodes and canonical CBOR re-encoding cannot replace the Transit encode-side interoperability proof, since Transit output is deliberately not byte-compared.

Required change: extend the peer harness to send the specified corpus and Jing payload through the actual old/new socket paths, compare deposited values under §4.4, and run both role assignments for both profiles in JVM and Node lanes. Preserve the documented baseline-exception semantics rather than asserting universal round trip. Record commands, build identities, counts and results. Dart may remain an explicitly named absent-coverage gap under §7.3.
