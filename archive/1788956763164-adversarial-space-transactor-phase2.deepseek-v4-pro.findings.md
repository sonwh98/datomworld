### 2. (non-blocking) `create!` throws a raw `IllegalArgumentException` for a non-associative spec, not the clean malformed-spec throw D2 promises

`transactor.cljc:173` — `(when (contains? spec :next-t) …)` runs before any map-shape guard. For a non-associative, non-nil spec (`(transactor/create! 42)`), `contains?` throws `IllegalArgumentException: contains? not supported on type: java.lang.Long`, not the `ex-info` the plan's D2 establishes ("create!'s failure modes are a malformed spec and a malformed retained history, both of which the caller can only abort on" — a clean throw). Every map case in `spec-validation` gets a clean message; the non-map case gets none, and no test covers it. Not a regression (v1's `ds/open!` failed opaquely through `defmulti` dispatch on a nil `:dao.stream/type`), so this is a robustness nit, not a defect. One-line fix: destructure-then-`(when-not (map? spec) (throw (ex-info "transactor spec must be a map" …)))` before the `contains?`.
