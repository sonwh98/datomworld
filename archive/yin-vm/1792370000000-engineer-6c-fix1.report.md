## Item 3: R1, collision preflight and harness scoping

:yin.k/unsupported :ambiguous-image {:yin.k/image ident :yin.k/segments #{A …}}

## Item 6: D4 fixtures

**Change (harness).** The primitive refusal in `layout-refusals` is now a table of four cases. Each refuses `[:yin.k/unsupported :continuation-registers]` on `:register` with zero attaches, and the stack lane continues each one to the reference value.

| Case | Program | Path |
|---|---|---|
| `:window` (existing) | `(conj [] (next-of c))` | `[:frames 0 :window r]` |
| `:lexical` | `((fn [q] (cat (cat [] read) (q [] 1))) conj)` | exactly `[:frames 0 :env q]` |
| `:captured` | `(let [g (fn [h] (fn [x] (h [] x)))] (let [k (g conj)] (cat (cat [] read) (k 2))))` | exactly `[:frames 0 :env k h]` |
| `:nested` | `((fn [w r] r) (cat [] conj) read)` | `[:frames 0 :window r 0]` (window register, then vector index 0) |

The lexical and captured programs read under `cat` rather than `s/then`. `then` and `let1` are lambda applications, so the operator closure saved in the window captures the binding too, and the path would then be `[:frames 0 :window 1 q]`. That is a legitimate refusal, but not the path these fixtures are meant to pin.

## A guard added after item 3

`image-collision` derives images from carried vectors before `rows/lower-task` has validated them. A tampered vector could therefore make `derive` throw a non-`:yin.k` error ahead of the carrier's own first-defect refusal. A vector that fails to derive now gets the unique identity `[::underivable A]`, which leaves its refusal to the carrier.
- The four-namespace quick tier and the wide quick sweep are both green after this change.
- No test exercises the guard directly.

## Uncertain

- **Item 5 harness search.** `ambiguous-dead-slots` counts only parking pcs (rule A1), not every boundary. That is enough for `lift-state`'s safepoint check, and C yields 38 fixtures.
- **Global code-index.** Several layout-test helpers still call `h/kernel-space` unscoped: `lifted-waits`, `envs`, `stack-frames` and `closures-round-trip`. They depend on no test projecting an alpha-equivalent of their vectors into the global code-index. I kept item 3's fixtures shape-unique for that reason. Scoping these call sites as well would make the guarantee structural rather than by convention.
- **Wider coverage.** `free-env-procedure` and `holds-procedure?` also refuse a closure nested in a guest collection in the free environment. The ruling names a closure or continuation "in" the free environment; I read nesting as included, because `walk-value` would carry it raw as well.
