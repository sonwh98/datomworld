**Findings**

1. **P1, test portability.** `test/yin/vm/linker/admission_test.cljc:1062-1089` (`traced-tick`) and `:1192-1209` (the bound test) use `with-redefs` with no reader conditional. Every other `with-redefs` in the portable tests is wrapped `#?(:cljd nil :default ...)` with the comment "unavailable on ClojureDart" (pipeline_test.cljc:334, scan_test.cljc:149, query_test.cljc:962). On the Dart lane the whole admission test namespace fails to load, which removes Dart coverage for every landed admission test, not just the four new ones. The brief required the acceptance tests on three hosts. Not verified by a run. Exact fix: wrap the `traced-tick` defn and the whole bound test in `#?(:cljd nil :default ...)`, cljd first. In tests A and B compute the result as `#?(:cljd {:result (repl/recheck-on-tick state [])} :default (traced-tick state))` and guard only the trace assertions and the successor-equality assertions. The functional assertions, serial 1 and empty asked and answers maps stay on all hosts. Test C can drop the trace and assert on state alone on Dart. Rerun the quick tier on JVM and the orchestrator's Dart lane.

2. **P3, stray key.** `repl.cljc:1451` stores the `retire` result, which carries `:retired [link-id ...]`, as the session's `:linker`. The vector persists in the value through every later round. Exact fix: `(dissoc retired :retired)` at the assoc, or have `retire` return the ids beside the value.

3. **P3, obscure identity preservation.** `repl.cljc:1979` compares the entire session map to decide whether to reuse the old state. Cheap in practice because unchanged entries short-circuit on identity, but the intent is hidden. Exact fix: compare only `(:linker state)` with `(:linker served)` and `(:dht state)` with `(:dht served)`.

4. **P3, docstring.** `drive-links` (repl.cljc:1287) does not document the `initial-progress` argument or that the first iteration skips the round when it is true. Add one sentence.

5. **Non-blocking note.** The tick's own round result, including its pending entries, is discarded when no progress is made. Correct today, because the state's `:links` from the last drive still describe the waits. Worth remembering if a later slice changes what the round reports.
