Objections to the cell ruling:

1. **The minimal boxing rule is too weak.** Python whole-block scope analysis is already required by [yang.antlr.md:1104](/Users/sto/workspace/datomworld/docs/design/yang.antlr.md:1104). Captures retain an environment at [ast_walker.cljc:530](/Users/sto/workspace/datomworld/src/cljc/yin/vm/ast_walker.cljc:530), and invocation restores it at [ast_walker.cljc:261](/Users/sto/workspace/datomworld/src/cljc/yin/vm/ast_walker.cljc:261). Consider `def f(): return x; x = 1; return f()` inside an enclosing function: `x` has only one assignment, but `f` needs the location established before that assignment. Box all local bindings for the spike; optimize only after binding and liveness analysis.

2. **Cells are a sound baseline, not a proof that alternatives are impossible.** [§8.1:992](/Users/sto/workspace/datomworld/docs/design/yang.antlr.md:992) explicitly permits state passing, and [§8.10:1229](/Users/sto/workspace/datomworld/docs/design/yang.antlr.md:1229) already requires an interop ABI. Those approaches have costs, but the ruling overstates their impossibility and inevitable allocation behavior. Likewise, a generator needs evolving identity, not necessarily this particular cell primitive. Choose cells because they simplify the selected lowering.

3. **Continuation authenticity must protect the authoritative payload.** Current recognition checks only the tag at [engine.cljc:60](/Users/sto/workspace/datomworld/src/cljc/yin/vm/engine.cljc:60). Existing resource seals cover only secret, kind, and ID at [engine.cljc:261](/Users/sto/workspace/datomworld/src/cljc/yin/vm/engine.cljc:261). Copying that seal onto a continuation map while trusting its editable `:k` or `:env` would leave tampering possible. A private payload table gives the seal a stable, authoritative referent without hashing live host functions.

4. **The cursor lift is not a cycle-safe implementation template.** [engine.cljc:606](/Users/sto/workspace/datomworld/src/cljc/yin/vm/engine.cljc:606) constructs the cursor payload before recording its mapping. Recursive heap encoding must instead reserve the identity **before traversing contents**, and lowering must allocate identities before filling cells. Also, the repeated-link issue at [engine.cljc:847](/Users/sto/workspace/datomworld/src/cljc/yin/vm/engine.cljc:847) is a correctness gate for slice 2, not merely a wart.

5. **F1 requires preserving authority that current registration discards.** Host registration stores raw functions and profile addresses at [module.cljc:210](/Users/sto/workspace/datomworld/src/cljc/yin/vm/module.cljc:210); application then passes only the primitive’s result onward at [ast_walker.cljc:251](/Users/sto/workspace/datomworld/src/cljc/yin/vm/ast_walker.cljc:251). Replacing `effect?` alone cannot fix this. Carry trusted profile authority through callable resolution and invocation, and validate the declared effect kind.
