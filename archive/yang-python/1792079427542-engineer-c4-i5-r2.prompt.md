**Root Cause**:
In `src/cljc/yang/python/antlr/lower.cljc` (`scc-module-specs`), the bundle uses `defs-expr` evaluating `(cell/new none)` and `cell/set!` to store forward references to module bodies. `cell-syms` (`%cell-m0`, `%cell-m1`, ...) are captured in the closures of the lowered module bodies (`wrapped-bodies`).
The Yin VM module linker (`yin.vm.engine/lift-slice`) strictly enforces code purity on published module stores: it refuses any lifted module containing a mutable `:cell-ref` (`:yin.k/non-portable :cell`). When an alias module attempts to read `pyscc.<bundle>/m0-body`, delivery fails.

- **P3**: `src/cljc/yang/python/antlr/lower.cljc:2104`: `scc-module-specs` bypasses `module-packet`'s module name validation (checking for empty, leading/trailing dots, `..`, and `$`). Run the same name check on each member before constructing `bundle-name`.

## Required Architectural Fix in `lower.cljc`
1. **Eliminate All Bundle-Time Cells**:
   Remove `cell-syms`, `cell-inits`, `cell-sets`, `defs-expr`, and `(cell/new none)` from `scc-module-specs`.
2. **Top-Level `yin/def` Definitions**:
   In `module-tree`, emit `spec-defs` and `body-defs` directly as top-level definitions in the bundle:
   ```clojure
   (module-tree (concat [(require-node prelude/module-name)]
                        spec-defs
                        body-defs))
   ```
   Each `spec-key` (`m0-spec`, `m1-spec`, ...) is `(u/def! spec-key (u/lit unit))`.
   Each `body-key` (`m0-body`, `m1-body`, ...) is `(u/def! body-key (u/lam [globals-sym globals-fn-sym] ...))`.
3. **Internal Sibling Delivery Rewriting**:
   Within `wrapped-bodies`, when a module imports a cyclic sibling in the same SCC:
   - `try-require` is rewritten to `(u/lit {:status :ok})`.
   - In `delivered`, reading sibling `spec` is rewritten to literal `{:name nm, :package? (boolean (:package? u))}`.
   - Sibling `body` reads (`pym.<sibling>/body`) are rewritten to read the bundle's own corresponding export `(u/v (symbol (str bundle-name) (str sibling-body-key)))`, or directly reference the sibling's top-level definition `(u/v sibling-body-key)`.
   Because all definitions in `module-tree` are top-level `yin/def` bindings in the bundle's environment, mutual function references between `m0-body` and `m1-body` resolve cleanly without capturing mutable cells!
4. **Member Name Validation**:
   In `scc-module-specs`, validate each member's `:name` using the same checks as `module-packet`:
   ```clojure
   (when (or (empty? name)
             (str/starts-with? name ".")
             (str/ends-with? name ".")
             (str/includes? name "..")
             (str/includes? name "$"))
     (throw (ex-info "a module name is dotted identifiers"
                     {:yang.python.antlr/diagnostic :yang.python.antlr/unsupported,
                      :construct "malformed module name",
                      :name name})))
   ```
