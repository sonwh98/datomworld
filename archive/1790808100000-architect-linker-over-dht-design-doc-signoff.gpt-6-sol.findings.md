**Judgment of the additions:** Retraction followed by assertion matches the existing fold; same-address consensus and key-file behavior honor the owner. Limiting module-level cross-definition reads to stack and register faithfully describes the current linker. Treating an encoder change as signature-breaking is accurate for the specified signed bytes, though it is a compatibility commitment. A synchronous Dart Ed25519 implementation is a valid requirement; the chosen package and its JVM/Node/Dart vector results must be established in L0. The footprint deferral is the remaining blocker to a frozen publisher contract.
